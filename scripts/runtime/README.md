# Executable Luau regression checks

`RunTests.luau` loads exact source from the freshly assembled authored-map build and executes the existing domain test modules in pinned Lune 0.10.5. It supplies Roblox datatypes and module resolution, not an alternate implementation of the game. Run from the repository root with `lune run scripts/runtime/RunTests.luau` after `scripts/Test-DevelopmentDeployment.ps1` has built the current source. The full validator runs both in that order.

Lune is a development dependency because type analysis alone does not execute assertions. The only service adapters are JSON encode/decode using Lune serde for the explicit memory fixture and deterministic unique GUIDs for lifecycle fencing; test clocks/backends remain the suite's injected dependencies. This runner has no networking, credentials, real DataStore, teleport, player input, rendering, or physics. Property/Growth/PropertyRendering suites use engine geometry and run in the Studio QA preview, not Lune. Client observers, real movement, multiplayer, and display tests also require Studio; published teleports and cross-session saves require the private experience. Unsupported operations fail rather than silently passing. Lune's notice about the saved Terrain's unsupported AssetContentMap is not a map fidelity result; the strict XML verifier checks the unchanged canonical scene separately.
