# Server responsibilities

Bootstrap starts AppRuntime, which resolves the trusted role before gameplay. Routing owns the manifest, transitions and teleport adapter. Entry never starts an economy, profile lease or Clash. TycoonRuntime owns Factory/Infinite lifecycle, attributes and income, returning prepare/recover hooks to Routing. Session owns the unchanged economy; its paused flag freezes Infinite income/credits/purchases during handoff. PlotWorld owns factory scaffolding; MapLayout validates the saved map before writes. SupplyRuntime/SupplyEvent own Factory's Supply Cache only.

Experiments/FactoryPurchases retains EXP-02's module paths and owns the default Factory walk-on sampling/one-use nonce guard. TycoonRuntime routes accepted offers through the common atomic Session purchase callback. Experiments/AimClash retains EXP-03's paths and owns the separate Clash-only practice/duel runtime and server Match. Neither the Clash queue nor property editing runs in Factory. Parry and performance diagnostic modules are not included.

Infinite uses Persistence/Profiles for lifecycle and its sole checkpoint scheduler. PropertyEdits owns non-yielding purchase/layout/palette transactions. PropertyWorld renders accepted property objects by revision; it never runs for Session. It retains unchanged models, replaces only moved/stored/content-changed objects, and recolors palettes in place through Models.setTheme. Per-model Content/PlacementFrame/PropertyTheme metadata is destroyed with the lot on departure; no owner data cache survives lot reuse. Shared Infinite/Catalogue, Placement and Models own definitions, geometry rules and bounded silhouettes. Models marks palette-colored parts explicitly and updates their RestColor too, preserving cosmetic activity after a palette change.

Infinite's private TycoonProperty RemoteFunction is limited to four requests per second per active player. Profiles validates ready lease, separate arrival epoch, exact lot, bounded primitive payload, monotonic sequence and expected property revision. An exact repeat of the latest request returns its previous result; older/reused sequences refuse. No preview motion sends a request. Server income is reconstructed from ownership, including stored equipment.
