# Factory purchase preview rules

`Rules.luau` owns the oriented root-center trigger, 0.6-stud exit hysteresis,
20 Hz sampling, 750 ms one-use offer deadline, client input gate and cosmetic
timings/culling. A menu/unaffordable/expired visit needs exit and re-entry; there
is no buy-on-funding or buy-on-menu-close. Economy and catalogue remain authoritative
in their existing shared/server modules.
